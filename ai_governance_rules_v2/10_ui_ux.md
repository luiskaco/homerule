# UI / UX Rules

## Principios
- claridad visual
- consistencia
- responsive design
- accesibilidad
- experiencia intuitiva

## UX
Debe incluir:
- loading states
- skeleton states
- error states
- success states
- empty states

## Skeleton Rules
- evitar layout shifts
- representar estructura real
- transición suave

## Accesibilidad
- navegación teclado
- labels correctos
- contraste adecuado

## Referencias
- Taste-Skill
- Skill
- Impeccable
