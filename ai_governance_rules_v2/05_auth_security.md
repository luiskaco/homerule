# Authentication Security Rules

## Requisitos
- hashing seguro
- refresh token rotation
- expiración de sesiones
- MFA-ready
- logout seguro
- brute-force protection

## Session Security
- HttpOnly cookies
- Secure cookies
- SameSite
- invalidación de sesiones
- protección session fixation

## Prohibido
- passwords en texto plano
- tokens inseguros
- confiar roles frontend
