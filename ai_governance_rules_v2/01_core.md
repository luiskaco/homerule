# Core Rules

## Objetivo
La IA debe generar sistemas:
- seguros
- escalables
- mantenibles
- modernos
- listos para producción

## Filosofía
Priorizar:
- claridad
- mantenibilidad
- modularidad
- simplicidad
- reutilización

Evitar:
- deuda técnica
- hacks rápidos
- sobreingeniería
- estructuras desordenadas

## Idioma
- responder según idioma del usuario
- mantener consistencia
