# Taste Skill

Anti-slop frontend framework. Mejora layout, tipografía, espaciado y motion
para evitar interfaces genéricas.

Diales disponibles en el SKILL.md instalado:
- DESIGN_VARIANCE: experimentación de layout (1-10)
- MOTION_INTENSITY: profundidad de animaciones (1-10)
- VISUAL_DENSITY: información por viewport (1-10)
