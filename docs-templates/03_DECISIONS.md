# Decisiones (ADR)

> Solo decisiones que tuvieron alternativas. Arriba, el índice: una línea por
> decisión. La IA lee el índice y abre solo el ADR que necesita.
> Un ADR no se borra: si cambia la decisión, se marca "Reemplazada por ADR-xxx".

|---|---|---|

## ADR-001 — Título de la decisión

**Fecha:** YYYY-MM-DD · **Estado:** Propuesta / Aceptada / Reemplazada por ADR-xxx

**Contexto:** _Qué problema forzó la decisión._

**Decisión:** _Qué se decidió._

**Alternativas:** _Qué otras opciones se evaluaron y por qué se descartaron._

**Consecuencias:** _Qué costos o límites quedan aceptados._
