# Stack Chooser — documentación de origen

Stack Chooser nació como el proyecto `makeStackWork` y hoy vive en Homerule
(`/stack`, ADR-042). Estos documentos son los originales de ese proyecto, sin
cambios, para conservar lo decidido y su historia. Lo vigente de Homerule está en
`docs/` (un nivel arriba); ante una diferencia, manda Homerule.

Los números de ADR de acá (ADR-001, ADR-003…) son del proyecto original y no
chocan con los de Homerule: citarlos siempre como "Stack Chooser ADR-00x".
